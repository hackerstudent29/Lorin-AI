- **15–18% per year** serves as **Front-end VLSI design, SoC architecture, physical design** (Sector: Semiconductor Design).

- **12–15% per year** serves as **RFIC design, signal processing, analog-digital integration** (Sector: Telecommunication (5G/6G)).

- **10–12% per year** serves as **ADAS chips, EV power management, sensor design** (Sector: Automotive Electronics).

- **10–12% per year** serves as **Low-power design, system-on-chip (SoC) design, embedded systems** (Sector: IoT & Consumer Electronics).

- **18–20% per year** serves as **AI accelerators, FPGAs, GPUs, edge computing hardware** (Sector: AI/ML Hardware).

- **8–10% per year** serves as **Verification engineers, automated test benches, DFT** (Sector: Test and Verification).

- **Very High** serves as **VLSI Design Engineer** (Skills Required: RTL design (Verilog/VHDL), FPGA design, ASIC design).

- **High** serves as **Verification Engineer** (Skills Required: UVM, SystemVerilog, functional verification, testbench development).

- **High** serves as **Layout Engineer** (Skills Required: Physical design, DRC/LVS, CAD tools (Mentor, Cadence)).

- **High** serves as **RFIC Design Engineer** (Skills Required: RF circuit design, communication systems, signal integrity).

- **Very High** serves as **Analog/Mixed-Signal Design Engineer** (Skills Required: Analog circuits, op-amps, DAC/ADC, simulation tools (Cadence, Synopsys)).

- **Moderate to High** serves as **Automotive VLSI Design Engineer (ADAS/EV)** (Skills Required: Power management ICs, automotive safety standards, sensor integration).

- **Very High** serves as **AI Hardware Design Engineer** (Skills Required: AI accelerators, GPU/FPGA design, neural network hardware).

- **High** serves as **Embedded Systems Engineer** (Skills Required: Embedded hardware, microcontroller programming, low-power circuits).
